# 江戸オク「ご利用ガイド（2025年2月版）」の読み取りと播州オクとの差分

出典：Instagram @medaka_factory_edo の20枚組投稿（スライド1〜12, 14〜20 を確認。13のみ未確認）
および公式サイト「オークション説明」ページ（2026年11月時点）。

凡例：✅ 実装済み ／ 🔶 一部実装 ／ ❌ 未実装

## 0. 概要と会員登録・ログイン（スライド2・3）

江戸オクが自ら挙げる主な特長：会員制リアルタイムオークション（自動延長・サドンデス）、OTP認証、LINE連携の入札速報・落札通知、桜吹雪・決闘演出・弾幕コメント、品評会（メダカフェア）の品評・投票、メダカ図鑑、フロント出品、PWA。

| 機能 | 江戸オクの仕様 | 播州オク |
|---|---|---|
| 会員登録フォーム | 氏名・メールアドレス・屋号・Instagram 等を入力 | ✅ 初回ログイン後に /register で入力 |
| ダブルオプトイン | 確認メールのリンクをクリックして本登録 | 🔶 OTP入力がメール確認を兼ねる |
| 管理者承認 | 承認後に入札・コメント・品評会参加が可能 | ✅ /admin/members で承認・停止。承認時にお知らせ |
| 重複登録 | 登録済みメールで再登録すると「登録済み案内」へ誘導 | ✅ 同じメールならそのままログイン |
| OTPログイン | マイページまたは入札画面の「ログイン」→メール入力→6桁コード（LINE連携済みならLINEにも）→セッション維持 | 🔶 メールのみ。LINEへの送信なし |
| LINEログイン | 連携済み会員は入札画面の「LINEでログイン」でワンタップ | ❌ |
| 認証コード有効期限 | 10分 | ✅ 10分、試行5回まで |

## 9. 実装の優先順位（提案）

**進捗**：第1段階（会員承認制、入札確認画面、上限額自動入札と競り負け履歴、サドンデス延長、キーワード検索、お気に入り）と第2段階（フロント出品、出品者ダッシュボード、取引ステータス、即決、手数料プラン、画像アップロード）は実装済み。

江戸オクと同じ土俵で戦うのに効く順。各段階は1〜2週間程度の規模。

1. **商売の土台**：会員承認制（SNS確認）、入札確認画面、上限額自動入札＋競り負け履歴、サドンデス延長、キーワード検索、お気に入り
2. **出品者を増やす**：フロント出品（承認制・PIN・即決価格・画像アップロード・テンプレート）、出品者ダッシュボード（取引ステータス、送料設定、発送通知）、手数料プラン
3. **囲い込み**：落札証明書と二次販売証明、会員ランクと闇市、限定オークション（合言葉）、千両箱
4. **熱を作る**：リアルタイム価格更新と入札速報、入札エフェクト・一騎打ち・10分前演出、弾幕コメント、瓦版と告知バー、YouTube動画・カルーセル
5. **周辺**：メダカ図鑑、品評会、ガチャ、LINEログインとOTPのLINE送信、ブラックリスト・通報
