# 播州オク — 播州めだか オークションシステム

播州めだか向けの会員制メダカオークション（Webアプリ）です。
Next.js 15（App Router）+ TypeScript + Tailwind CSS + SQLite（Node.js 内蔵 `node:sqlite`）で構成し、外部サービスなしで動作します。

## 機能

| 機能 | 内容 |
|---|---|
| 入場ゲート | トップページで円を長押しするとオークション会場へ転送（スキップ可） |
| オークション一覧 | 開催中／終了分タブ、キーワード検索、本日・明日・3日以内の絞り込み、高額順・安値順などの並び替え、ページング、お気に入り♡ |
| 出品詳細・入札 | **上限額方式の自動入札**（見えざる戦い）、入札確認画面、競り負け履歴、残り時間カウントダウン、入札履歴、**終了5分以内の入札で自動延長（サドンデス対応）** |
| 会員認証 | メールアドレス＋6桁認証コード（パスワード不要）。初回ログイン後に登録フォーム（氏名・屋号・SNS・発送先）、**管理者承認後に入札可**（`REQUIRE_APPROVAL=false` で承認不要に） |
| マイページ | 発送先登録、入札中・落札品一覧、お知らせ、LINE連携、フォロー中出品者 |
| 出品者フォロー | ☆でフォローすると新規出品を通知 |
| 通知 | 高値更新・落札・新規出品をアプリ内通知。LINE連携済みなら LINE push、落札時はメールも送信 |
| 出品者ポータル（/sell） | 承認会員が**メール＋PIN認証**で出品。即決価格、画像アップロード（最大6枚）、YouTube動画、サブタイトル、説明文テンプレート（10件）、連続出品。管理者の確認後に公開 |
| 出品者ダッシュボード | 自分の出品、落札者と発送先、取引ステータス（お支払い待ち→入金確認→発送済み→受け取り完了）、発送通知（配送業者・追跡番号）、売上・手数料・お戻しの集計、送料（常温／クール）と支払い案内の設定 |
| 取引のいま | 落札者のマイページに4段階の進捗、お支払い合計（落札額＋送料）、出品者の支払い案内、受け取り完了ボタン |
| 即決 | 即決価格つきの出品は確認画面を経て即落札 |
| 手数料プラン | セルフ10%／サポート30%／フル50%（`FEE_PLANS` で変更可）。出品者ごとに個別指定も可 |
| 落札販売証明書 | 入金確認後に落札者が発行（証明番号 BM-XXXX-XXXX）。公開照合ページ、殖やした子の**二次販売証明**の申請とお店の発行、系図表示 |
| 会員ランク | 累計落札額でランクが上がる（`RANKS` で名称と閾値を設定）。マイページと入札画面に表示 |
| 特殊オークション | 🌑闇市（ランク以上のみ入札）、🔒限定（合言葉）、📦千両箱（落札者だけが中身を見られるシルエット表示） |
| ライブ表示 | 入札画面が3秒ごとに自動更新（価格・履歴・HH:MM:SS カウントダウン）。入札エフェクト、高額入札の桜吹雪、一騎打ちとVSバー、🔥ヒートアップ自動判定、終了10分前の煽り。音・演出は各自で入切 |
| 弾幕コメント | 承認会員が投稿、画面上を流れる。入札で「○○さんキター!!」を自動投稿。出品ごとに入切 |
| 入札速報・瓦版・告知 | 全ページ下部の速報ティッカー、左下の瓦版（お知らせと激戦の品の記事）、緊急告知バー、でか文字放送（管理画面から掲載） |
| 管理画面 | 会員の承認・停止、出品者アカウント（会員紐づけ・手数料プラン・PIN発行）、確認待ち出品の公開／却下、新規出品、取消、落札者と取引状態の一覧 |
| 法務ページ | オークション説明、特定商取引法に基づく表記、利用規約、プライバシーポリシー |
| PWA | ホーム画面に追加して利用可能（manifest 同梱） |

## 動かし方

Node.js 22.18 以上が必要です。

```bash
npm install
cp .env.example .env        # 必要に応じて編集
npm run seed                # デモデータ投入（任意）
npm run dev                 # http://localhost:3000
```

- 管理者にしたいメールアドレスを `.env` の `ADMIN_EMAILS` に設定し、そのアドレスでログインすると「管理」メニューが出ます。
- メール送信（`SMTP_*`）が未設定の間は、認証コードがサーバーログに出力され、開発モードでは画面にも表示されます。

本番は `npm run build && npm start` です。`DATABASE_PATH` の SQLite ファイルを永続化してください。

## 外部サービスの設定（任意）

- **メール**: `SMTP_HOST` などを設定すると認証コードと落札通知を実際に送信します。
- **LINE**: LINE Developers で Messaging API チャネルを作り、`LINE_CHANNEL_ACCESS_TOKEN` と `LINE_CHANNEL_SECRET` を設定。
  Webhook URL を `https://<ドメイン>/api/line/webhook` にすると、友だち追加または「連携」と送信した人に連携コードを返信します。
  会員はそのコードをマイページに登録すると LINE 通知を受け取れます。
- **終了処理**: 画面アクセス時に自動で終了・落札確定しますが、アクセスが無い時間帯でも即時通知したい場合は
  `GET /api/cron/finalize`（`CRON_SECRET` を設定した場合は `Authorization: Bearer` 必須）を数分おきに叩いてください。
- **特定商取引法表記**: `LEGAL_*` 環境変数で所在地などを設定してください。

## 構成

```
src/lib/        DB・認証・入札ロジック・通知・設定
src/app/        画面（/ 入場, /auctions 一覧, /auctions/[id] 詳細, /login, /mypage, /sellers/[slug], /admin, /legal/*, /guide）
src/app/api/    cron 終了処理、LINE webhook
scripts/seed.ts デモデータ
tests/          node:test によるドメインテスト
```
