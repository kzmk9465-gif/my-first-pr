- 決済: `src/lib/oripa.ts` の oripaProvider() は DEMO_MODE=1 のとき必ず **mock(テスト決済)**。注文画面に「お試し環境のため…テスト決済で進みます。お金は動きません」と出て、「支払いを完了する（テスト）」を押すだけ。決済代行・カード・銀行振込は一切呼びません(mockPayOripaAction は provider が mock 以外なら何もしない)。
- 在庫: デモの3つのくじ(播州極上ラメくじ／流星スペシャルくじ／朱龍プレミアムくじ)は seed-demo.ts が入れた**デモ用の仮データ**です。本番サービス(render.yaml の `banshu-oku`)はまだ作っておらず、本番DBも存在しません。デモで引いても減るのはデモ箱の口数だけで、実在の魚・本番の在庫は動きません。

## 2. 操作手順と、照合する3か所
1. ログイン後 /oripa で「流星スペシャルくじ」の口数を 1 にして「口を買う」→ 注文画面で「支払いを完了する（テスト）」。
2. /oripa に戻ると「引ける口があります」→「1口引く」→ 球をタップして開封。
   - **【抽選直後】** 当選結果カードの「賞」と「景品名」を控える。下に「🎬 一番良い当たりの演出を見る（○賞）」が出る(リンク先は /gacha/index.html?draw=<記録ID>)。
3. そのリンクを開く → 画面下に「流星スペシャルくじ｜○賞「景品名」（記録ID n）の演出を再生します」と出る → 「演出をスタート」。
   - **【演出後】** 当選画面の文字と結果画面の「○賞 獲得」「景品名」「記録ID」を、①と照合。「もう一度見る」で同じ記録を再生。
4. /oripa の「発送依頼がまだの当選品」一覧にある「演出を見る」からもう一度開く。
   - **【再表示後】** 同じ記録ID・同じ賞・同じ景品名であることを照合。
5. (任意)演出ページのURL末尾に `&rank=SS` を付けて開いても、等級・景品は変わらない(本番モードでは ?rank= を無視)。
- 画像について: デモのくじの景品には写真が登録されていないため、演出ページの魚は共通の仮画像(medaka.png)です。賞品に写真(image_url)を登録すると、その写真が出ます(ローカルの型は確認済み・写真付きの実データでの表示は未確認)。
